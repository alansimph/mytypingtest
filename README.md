# myTypingTest

A browser game that helps children learn a keyboard: letters, then words, then sentences.

Beginner lessons are ready to play. Each one asks for one key at a time and highlights that key. Intermediate and Expert are still locked.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints. A laptop or desktop keyboard is the better way to practice.

Progress and the sound setting stay in this browser. There is no account and no server.
