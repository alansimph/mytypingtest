# myTypingTest

A browser game that helps children learn a keyboard: letters, then words, then sentences, then paragraphs.

Beginner lessons teach one key at a time. Intermediate lessons are short words, then longer ones. Expert lessons are sentences with capitals and simple punctuation. Master lessons are paragraphs of at least 50 words. Each key is marked with the home-row finger that presses it. A 3D capybara watches the lesson: a right key brings a present, and a wrong key brings a silly mess. Finishing a lesson pops the stars you earned, says how long that try took, and plays a short tune when sound is on. Beginner, Intermediate, and Expert stars come from accuracy. Master stars come from speed: finishing is 1 star, 40 words a minute is 2, and 60 words a minute is 3. Stars are saved in this browser and shown on the lesson list. Each level opens after the one before it is finished.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints. A laptop or desktop keyboard is the better way to practice.

Progress and the sound setting stay in this browser. There is no account and no server.
